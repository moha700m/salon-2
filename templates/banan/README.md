# قالب بنان

هذا هو القالب المرجعي لأي مشغل جديد.

الأقسام الأساسية:
- Hero باسم المشغل والتقييم والعنوان.
- الخدمات.
- أسباب الاختيار والثقة.
- تقييمات Google.
- الموقع وساعات العمل.
- أزرار Google Maps وWhatsApp.
- نموذج حجز مباشر.
- Footer بمعلومات التواصل.

قواعد البيانات:
- لا نختلق أسعارًا.
- لا نختلق أسماء فريق.
- إذا لم تظهر الصور أو الخدمات الرسمية، تظهر ضمن قائمة النواقص ليتم طلبها من العميل.
- كل مشغل يحصل على معرف مستقل ورابط معاينة مستقل وحجوزات منفصلة.
