# مشاغل — Mashaghel Site Factory

منصة داخلية لإنشاء مواقع مشاغل وصالونات بسرعة من رابط Google Maps.

## الفكرة
1. الصق رابط Google Maps.
2. النظام يستخرج البيانات العامة المتاحة: الاسم، التصنيف، العنوان، الهاتف، الموقع، التقييم، عدد المراجعات، ساعات العمل، الخدمات والمراجعات الظاهرة.
3. البيانات تتحول إلى `SalonProfile` موحد.
4. يتم تركيبها على قالب `templates/banan`.
5. ينشأ رابط معاينة مستقل للمشغل.
6. الموقع الناتج يحتوي على خدمات، خرائط، واتساب، تقييمات وحجز مباشر.

## النسخة الحية
- App backend/source runtime: https://app-txxguu.v2.appdeploy.ai/
- Vercel production proxy project: `mashaghel-ai`

## الهيكل
- `templates/banan/` القالب المرجعي المستوحى من مشروع بنان.
- `schemas/salon-profile.json` مخطط البيانات الموحد لأي مشغل.
- `docs/workflow.md` سير العمل من Google Maps إلى رابط المعاينة.
- `vercel.json` يوجّه مشروع Vercel إلى النسخة التشغيلية التي تحتوي على AI وقاعدة البيانات.

## قواعد القالب
- عربي RTL وMobile First.
- تصميم فاخر وهادئ مناسب لصالونات التجميل.
- لا يتم اختراع أسعار أو معلومات غير موجودة في المصدر.
- الصور الرسمية والخدمات والأسعار الدقيقة تُعتبر نواقص عند عدم توفرها، ويطلبها النظام من العميل لاحقًا.
- أي مشغل جديد يستخدم نفس البنية مع بيانات مستقلة وحجوزات مستقلة.

## الحالة
MVP عامل: توليد نموذج، رابط معاينة مستقل، حفظ البيانات، وحجز لكل موقع.
